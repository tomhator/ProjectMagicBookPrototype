# 마법서 공방 — 크래프팅 프로토타입

> 검증 질문: **"마법서를 만드는 행위 자체가 재미있는가?"**

의뢰를 읽고 → 마법진을 조합하고 → 주문을 짓고 → 페이지를 꾸며 → 납품하는
코어 루프를 한 화면에서 체험할 수 있는 웹 프로토타입입니다.
빌드 도구 없이 순수 HTML/CSS/JS로 작성되어, 파일만 열면 바로 실행됩니다.

## 실행 방법

```bash
# 방법 1) 그냥 index.html 더블클릭

# 방법 2) 로컬 서버 (권장)
python3 -m http.server 8000
# → http://localhost:8000 접속
```

## 게임 흐름

1. **의뢰 분석** — 의뢰문에서 위협 키워드(독·뱀·산·저주…)를 찾아내고,
   각 위협의 *상극 룬*과 추천 강조 방향을 알려줍니다.
2. **① 마법진** — 기반 원(◯)을 세우고, 위협의 상극 룬을 빈 자리에 새깁니다.
   삼각형(증폭)·사각형(안정)을 더하고, 룬 두 개를 연결해 콤보를 만듭니다.
3. **② 주문** — 대상·행위·표적·어조 단어를 조합해 의뢰에 맞는 문장을 짓습니다.
   마법서(book)는 더 길고 정확한 주문을 요구합니다.
4. **③ 꾸미기** — 종이 외곽선, 마법진 선 굵기·색·채움·광휘, 주문 핵심어 강조.
5. **④ 배치** — 배치 형태와 "무엇을 크게 강조할지"를 정합니다.
6. **납품** — 우측 미리보기가 실시간으로 갱신되며, 납품 시 점수·별점·보수·개선 힌트를 받습니다.

## 점수 설계 (요약)

- **최소 요구**: 기반 원 + 핵심 위협의 상극 룬 + 최소 길이 주문 → 미달 시 반려.
- **가점**: 위협별 룬 대응(룬+주문 이중 대응 추가점), 증폭/안정/콤보,
  주문 적합도·길이·어조, 핵심어 강조, 의뢰 성격에 맞는 배치 판단.

## 파일 구조

| 파일 | 역할 |
|------|------|
| `index.html` | 화면 구조 |
| `styles.css` | 아케인 다크 테마 + 양피지 미리보기 |
| `data.js` | 의뢰·룬·도형·단어·위협↔상극 데이터 |
| `score.js` | 의뢰 분석 & 점수 계산 엔진 |
| `app.js` | 상태·렌더링·상호작용 |

## 다음에 검증/확장하면 좋을 것

- 룬 콤보의 시너지 규칙을 더 깊게(상극 외 *조합* 효과).
- 직접 작성 vs 템플릿 제공의 균형 (현재는 직접 조합 중심).
- 의뢰 난이도 곡선과 보수 밸런스, 시간/자원 제약.
- "재미 검증"용 간단한 설문/피드백 수집.
