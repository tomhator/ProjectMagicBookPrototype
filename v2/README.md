# 마법서 공방 v2 — 오행 프로토타입

v1의 핵심(마법서 제작 행위)은 유지하되, 리뷰에서 나온 진입 장벽
(**해석이 어렵다 · 공식이 어렵다 · 정보량이 많다**)을 **오행(五行)** 으로 단순화한 버전.

`v2/index.html` 단일 파일. 빌드 없이 열면 바로 실행됩니다.

## 큰 루프

```
[새 유형 의뢰] → 직접 제작 → 납품 + 청사진 자동 등록
        → 같은 유형 재등장 시 → 프린터로 즉시 제작(골드 소모) → 납품
        → 더 어려운 의뢰 해금 → 다시 직접 제작 …
```

- **판매 탭**: NPC 손님이 의뢰를 들고 옴(좋은 피자 위대한 피자 식). 클릭하면
  청사진(📐) 유무 검사 → 있으면 프린터 즉시 제작, 없으면(🆕) 직접 제작으로 이동.
- **제작 탭**: 의뢰의 위협 원소를 보고 오행 바퀴를 참고하며 마법진을 만든다.

## 오행 규칙 (해석·공식의 단순화)

상생 순서 인덱스: **목0 · 화1 · 토2 · 금3 · 수4**

- **도형 = 상극(剋)**: 위협 원소 `T`를 제압하는 도형 = `(T+3)%5`
  - 예: 화(火) 위협 → 수(水) 도형 — *수극화*
- **룬 = 상생(生)**: 도형 원소 `E`를 키우는 룬 = `(E+4)%5`
  - 예: 수(水) 도형 → 금(金) 룬 — *금생수*

원소마다 고유 도형: 목=세로직사각형 · 화=삼각형 · 토=정사각형 · 금=원 · 수=마름모.

## 제작 규칙

- **도형**: 최대 5개. 추가할수록 중심에서 바깥으로 겹겹이 쌓이며 작아짐.
- **룬**: 활성 도형당 최대 5칸. `조합 모드`를 켜면 한 칸에 룬 2개를 부착(상생+자기강화 콤보 보너스).
- **버튼 클릭 = 순서대로 자동 배치** (드래그 없음).
- 난이도(tier)별 요구 도형 수·룬 수가 달라지고, **품질(%)** 이 청사진과 수익에 반영됨.
